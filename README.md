# Date Invitation 💗

A responsive pink-and-white date invitation that works as a static GitHub Pages site.

## Set up the link

After publishing, open:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/setup.html
```

Fill in the plan, date, time, and location. The page generates the recipient link to send.

## Publish with GitHub Pages

1. Create a GitHub repository and push these files to its `main` branch.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. GitHub will show the public URL when the site is ready.

No build step or dependencies are required.
